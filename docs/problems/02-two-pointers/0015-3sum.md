# 3Sum

<ProblemMeta />

## Problem

You are given a list of integers `nums`. Return every set of three values, taken from three different positions, that adds up to zero. Each triplet may appear only once in the answer, even if the list offers several ways to build it.

| Input | Output |
| --- | --- |
| `[-3, 1, 2, 0, 3]` | `[[-3, 0, 3], [-3, 1, 2]]` |
| `[0, 0, 0, 0]` | `[[0, 0, 0]]` |
| `[1, 2, 3]` | `[]` |

::: details Solution
**Idea.** Sort the list. Then fix the smallest number of the triplet, `nums[i]`, and look for two numbers to its right that add up to `-nums[i]`. On a sorted list that is exactly [Two Sum II](/problems/two-sum-ii-input-array-is-sorted): one pointer just after `i`, one at the end, move the left one when the sum is too small and the right one when it is too big.

Sorting also solves the duplicates. Equal values sit next to each other, so a repeated triplet can only come from starting with the same first value again or the same second value again. Skip `i` when it equals the value before it, and after recording a triplet move `left` past all copies of the value it just used. Once the first two values of a triplet are fixed the third is fixed too, so nothing else can repeat.

If `nums[i]` is positive the loop can stop: everything to its right is at least as large, so no sum can reach zero.

```python
class Solution:
    def threeSum(self, nums: list[int]) -> list[list[int]]:
        nums = sorted(nums)
        result = []
        for i in range(len(nums) - 2):
            if nums[i] > 0:
                break
            if i > 0 and nums[i] == nums[i - 1]:
                continue
            left, right = i + 1, len(nums) - 1
            while left < right:
                total = nums[i] + nums[left] + nums[right]
                if total < 0:
                    left += 1
                elif total > 0:
                    right -= 1
                else:
                    result.append([nums[i], nums[left], nums[right]])
                    left += 1
                    right -= 1
                    while left < right and nums[left] == nums[left - 1]:
                        left += 1
        return result


def show(triplets):
    print(sorted(sorted(triplet) for triplet in triplets or []))


show(Solution().threeSum([-3, 1, 2, 0, 3]))
show(Solution().threeSum([-1, 0, 1, 2, -1, -4]))
show(Solution().threeSum([0, 0, 0, 0]))
show(Solution().threeSum([-2, 0, 1, 1, 2]))
show(Solution().threeSum([1, 2, 3]))
```

**Time** `O(n²)`: the sort is `O(n log n)` and each of the `n` first numbers gets one linear two pointer pass. **Space** `O(n)` for the sorted copy, not counting the answer.

**With a set.** The inner search can also be the dictionary idea from [Two Sum](/problems/two-sum): walk the numbers after `i`, and for each one ask whether the value that completes the triplet was already seen. Storing the triplets as tuples in a set removes duplicates without any pointer bookkeeping. The running time is the same, but it uses more memory.

```python
class Solution:
    def threeSum(self, nums: list[int]) -> list[list[int]]:
        nums = sorted(nums)
        found = set()
        for i in range(len(nums) - 2):
            if i > 0 and nums[i] == nums[i - 1]:
                continue
            seen = set()
            for j in range(i + 1, len(nums)):
                need = -nums[i] - nums[j]
                if need in seen:
                    found.add((nums[i], need, nums[j]))
                seen.add(nums[j])
        return [list(triplet) for triplet in found]


def show(triplets):
    print(sorted(sorted(triplet) for triplet in triplets or []))


show(Solution().threeSum([-3, 1, 2, 0, 3]))
show(Solution().threeSum([-1, 0, 1, 2, -1, -4]))
show(Solution().threeSum([0, 0, 0, 0]))
show(Solution().threeSum([-2, 0, 1, 1, 2]))
show(Solution().threeSum([1, 2, 3]))
```

**Time** `O(n²)`, **space** `O(n)` plus the set of answers.
