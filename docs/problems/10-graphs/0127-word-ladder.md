# Word Ladder

<ProblemMeta />

## Problem

You are given two words of the same length, `beginWord` and `endWord`, and a list of allowed words `wordList`. In one move you may change a single letter of the current word, and the result must be in `wordList`. Return the number of words in the shortest chain from `beginWord` to `endWord`, counting both ends. Return `0` if no chain exists. `beginWord` does not have to be in the list, but `endWord` does.

| Input | Output | Why |
| --- | --- | --- |
| `"cold"`, `"warm"`, `["cord", "card", "ward", "warm", "worm"]` | `5` | cold, cord, card, ward, warm |
| `"cat"`, `"dog"`, `["cot", "cog"]` | `0` | `"dog"` is not an allowed word |

::: details Solution
**Idea.** Think of every word as a node, with an edge between two words that differ in exactly one letter. The question asks for the shortest path from `beginWord` to `endWord`. All edges cost the same, so breadth-first search finds it: the search reaches words in order of distance, and the first time it reaches `endWord` is along a shortest chain.

The slow part is finding a word's neighbours. Comparing every pair of words is too much for a long list. Instead, give each word one pattern per position, with that position replaced by `*`. The patterns of `"cord"` are `"*ord"`, `"c*rd"`, `"co*d"` and `"cor*"`. Two words differ in one letter exactly when they share a pattern, so a dictionary from pattern to words gives the neighbours directly.

A word is added to `seen` when it is queued, so it is queued once. Each queue entry carries the number of words in the chain that led to it.

```python
from collections import deque


class Solution:
    def ladderLength(self, beginWord: str, endWord: str, wordList: list[str]) -> int:
        if endWord not in wordList:
            return 0

        buckets = {}
        for word in wordList:
            for i in range(len(word)):
                buckets.setdefault(word[:i] + "*" + word[i + 1:], []).append(word)

        seen = {beginWord}
        queue = deque([(beginWord, 1)])
        while queue:
            word, length = queue.popleft()
            if word == endWord:
                return length
            for i in range(len(word)):
                for nxt in buckets.get(word[:i] + "*" + word[i + 1:], []):
                    if nxt not in seen:
                        seen.add(nxt)
                        queue.append((nxt, length + 1))
        return 0


print(Solution().ladderLength("cold", "warm", ["cord", "card", "ward", "warm", "worm"]))
print(Solution().ladderLength("cat", "dog", ["cot", "cog"]))
print(Solution().ladderLength("cat", "dog", ["cot", "dig", "dog"]))
print(Solution().ladderLength("lead", "gold", ["load", "goad", "gold", "lend", "bold", "gild"]))
print(Solution().ladderLength("a", "c", ["a", "b", "c"]))
```

**Time** `O(n² · L)` in the worst case for `n` words of length `L`, when many words share a pattern, and close to `O(n · L²)` on typical word lists. **Space** `O(n · L²)` for the patterns.

**Search from both ends.** A breadth-first search grows wider with every level. Two searches that each cover half the distance, one from `beginWord` and one from `endWord`, visit far fewer words than one search covering all of it. Keep the two frontiers as sets and always expand the smaller one. The chain is complete as soon as a neighbour of one frontier lies in the other.

Here the neighbours are generated by trying all 26 letters at each position and keeping the results that are allowed words.

```python
class Solution:
    def ladderLength(self, beginWord: str, endWord: str, wordList: list[str]) -> int:
        words = set(wordList)
        if endWord not in words:
            return 0

        front, back = {beginWord}, {endWord}
        seen = {beginWord, endWord}
        length = 1
        while front and back:
            if len(front) > len(back):
                front, back = back, front
            length += 1
            next_front = set()
            for word in front:
                for i in range(len(word)):
                    for letter in "abcdefghijklmnopqrstuvwxyz":
                        candidate = word[:i] + letter + word[i + 1:]
                        if candidate in back:
                            return length
                        if candidate in words and candidate not in seen:
                            seen.add(candidate)
                            next_front.add(candidate)
            front = next_front
        return 0


print(Solution().ladderLength("cold", "warm", ["cord", "card", "ward", "warm", "worm"]))
print(Solution().ladderLength("cat", "dog", ["cot", "cog"]))
print(Solution().ladderLength("cat", "dog", ["cot", "dig", "dog"]))
print(Solution().ladderLength("lead", "gold", ["load", "goad", "gold", "lend", "bold", "gild"]))
print(Solution().ladderLength("a", "c", ["a", "b", "c"]))
```

**Time** `O(n · L² · 26)` in the worst case, **space** `O(n · L)`.
