# Playground

Try out small ideas here. Press **Ctrl + Enter** (Mac: **⌘ + Enter**) to run your code. **Stop** restarts the Python session.

<ClientOnly><PythonPlayground /></ClientOnly>

## Good to know

- Each run starts with fresh variables.
- The standard library is built in, so `collections`, `heapq`, `bisect` and `itertools` all work.
- Runs are stopped after 15 seconds. A solution that takes longer than that is usually stuck in a loop.
- There is no network access.
